# Excelerate Opportunity Analytics Dashboard

An interactive **Looker Studio dashboard** developed as part of the Excelerate Data Visualization Trainee Internship with Team 10.

This project explores opportunity listings and presents patterns through an interactive visual report. This repository focuses on the dashboard, its purpose, and my individual contribution.

## Project Objectives

- Explore opportunity listings across categories and locations.
- Present patterns in opportunity duration, scholarship availability, and listing creation trends.
- Make the analysis easier to navigate through interactive visualizations.
- Communicate findings clearly while considering data-quality limitations.

## My Contribution

This was a collaborative team project. My individual responsibility was the **design and development of the interactive Looker Studio dashboard**. I translated the team's analysis into visualizations and organized the report to help viewers explore the opportunity data.

The wider team workflow included data preparation, cleaning, and exploratory analysis.

## Tools Used

- **Looker Studio** — interactive dashboard development and visual reporting
- **Microsoft Excel** — data review and analysis
- **Power Query** — data preparation and transformation
- **PivotTables and PivotCharts** — summarization and exploratory analysis

## Skills Demonstrated

- Interactive dashboard development
- Data visualization and analytical storytelling
- KPI and category-based reporting
- Dashboard layout and usability
- Communicating analytical findings to an audience

## Data Interpretation

The dashboard presents patterns in opportunity listings. These patterns should not be interpreted as confirmed placements or as a complete census of all available opportunities. Data-quality limitations may affect interpretation.
